BongoCat Live2D 平板触控 v4

需要包含 Live2D 内置管线渲染修复的新版 APK，旧版 APK 仍可能只显示平板。

使用方法：
1. 数据管理 -> 游玩皮肤 -> 导入，选择 BongoCatLive2DTouchSkin-v3.zip。
2. 在皮肤列表中选中 BongoCat Live2D 平板触控 v3。
3. 进入歌曲，在触控板左右两侧按下、移动、抬手。
4. 左侧中部的小猫，两只爪子分别跟随左右触点中心；无触点恢复抬手。
5. 暂停时不响应底层触摸；继续倒计时恢复表现，不参与提前判定。

本包只提供 Live2D 模型、贴图和平板；音符等未提供的资源使用内置基础皮肤。
位置由 ui/gameplay-ui.json 的 live2d 决定，游戏不锁定猫的位置。
平板由 live2d.background 声明，使用猫模型的坐标，与猫一起缩放，不随屏幕比例分离。
猫的 L/R 是面向玩家的左右，所以参数映射已交换，使屏幕左侧驱动左侧猫爪。
隐藏了摇杆标记和额外表情部件，没有为触控配置闪电动作。
v4 将玩家左侧的爪子横向范围收进平板，避免最外侧触点把爪子带到屏幕外。与旧版皮肤使用不同 ID，可以同时安装，测试时请选 v4。
