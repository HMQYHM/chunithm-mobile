# CHUNITHM Mobile

CHUNITHM に影響を受けた独立した Unity モバイルプロジェクトです。ゲームクライアント、マルチプレイサーバー、Skin Studio を含みます。

- 現在のバージョン：**0.3.3**
- Unity：2022.3.62f3c1
- Android：Android 7.0 以上、ARM64、Vulkan / OpenGL ES 3
- iOS：iOS 15 以上。ご自身の Apple 署名が必要です
- サーバー：Node.js 標準モジュール + WebSocket
- スキンエディター：ブラウザー版と Electron デスクトップ版

## ダウンロード

[GitHub Releases](https://github.com/HMQYHM/chunithm-mobile/releases) から APK と IPA をダウンロードしてください。

`CHUNITHMMobile-0.3.3-223-unsigned.ipa` は未署名 IPA です。直接インストールすることはできません。Xcode でご自身の開発者アカウントと provisioning profile を使って再署名してください。
