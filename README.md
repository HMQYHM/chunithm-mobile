# CHUNITHM Mobile

[简体中文](#简体中文) · [繁體中文](#繁體中文) · [日本語](#日本語) · [English](#english)

## 简体中文

CHUNITHM Mobile 是一个独立的 Unity 移动端项目，目标是把 CHUNITHM 的游玩体验带到移动端。当前 0.3.4 发布内容包括 Android APK、iOS 未签名 IPA、Skin Studio 源码、完整示例皮肤包，以及可公开的联机核心服务端归档。

### 下载与文档

- [GitHub Releases](https://github.com/HMQYHM/chunithm-mobile/releases)
- [项目说明网站](https://hmqyhm.github.io/chunithm-mobile/)
- [Skin Studio 完整说明](docs/skin-studio/SKIN-STUDIO-COMPLETE.zh-CN.md)
- [Skin Studio 工作流程](docs/skin-studio/SKIN-STUDIO-WORKFLOW.zh-CN.md)
- [Skin Studio 源码归档](releases/CHUNITHM-Mobile-SkinStudio-0.3.4-source.zip)
- [完整示例皮肤包](releases/CHUNITHM-Mobile-SkinStudio-Complete-Example-0.3.4.zip)

APK 与 IPA 请以 Release 中实际上传的文件为准。当前 IPA 为未签名构建，需要在 Xcode 中使用自己的开发者账号、Team 和 provisioning profile 重新签名后安装。Android APK 使用项目调试密钥构建。

### 当前已公开的内容

- 游戏版本 0.3.4 的 Android 构建和 iOS 未签名构建。
- Skin Studio 的布局、资源、场景、规则和 Live2D 配置编辑能力及四语言完整说明。
- 一个包含 Live2D、触控板、游玩 UI 和资源示例的完整示例皮肤包。
- 仅包含联机核心所需文件的 Node.js 服务端归档；配置示例不含密钥、运行数据或 Bot 凭据。

## English

CHUNITHM Mobile is an independent Unity project that brings the CHUNITHM play experience to mobile devices. Version 0.3.4 provides an Android APK, an unsigned iOS IPA, Skin Studio source, a complete sample skin package, and a publishable multiplayer-core server archive.

- [GitHub Releases](https://github.com/HMQYHM/chunithm-mobile/releases) · [Project website](https://hmqyhm.github.io/chunithm-mobile/)
- [Complete Skin Studio guide](docs/skin-studio/SKIN-STUDIO-COMPLETE.en.md)
- [Skin Studio source](releases/CHUNITHM-Mobile-SkinStudio-0.3.4-source.zip)
- [Complete sample skin](releases/CHUNITHM-Mobile-SkinStudio-Complete-Example-0.3.4.zip)

The IPA is an unsigned build and must be re-signed in Xcode with your own developer account, Team, and provisioning profile. The public server archive contains only the multiplayer core; it does not contain keys, runtime data, or bot credentials.
