# 地面 Note 贴图适配

`notes/tap_01.png` 到 `tap_16.png` 等编号仍表示谱面的实际格数。每个编号的图片均独立读取，不再要求作者猜测主体应按 64px 递增或套用固定尺寸档位。

自定义 TAP、EX TAP（使用平面 TAP 模型）、HOLD、SLIDE、FLICK、地雷及地面长条尾部，使用矩形 UV 模型时会按 PNG 的横向非透明范围适配。画满画布、居中留白、不对称留白均支持；边界额外保留两像素透明余量，纵向 UV、模型形状、判定宽度不变。全透明图片保持透明。

原模型如 `tap_03` 的 U 范围为 0.125～0.875；直接替换成画满画布的图会裁掉两侧。新适配将这个范围映射至实际主体范围，而不修改源 OBJ 或 PNG。内置皮肤不做此转换；带内部 UV 分割的复杂模型保留作者映射，AIR 等立体模型也保持原映射。

扫描及网格适配在皮肤加载/刷新时缓存，游玩期间不重复扫描；切换皮肤后重新建立缓存。无需重新导入现有皮肤包。
