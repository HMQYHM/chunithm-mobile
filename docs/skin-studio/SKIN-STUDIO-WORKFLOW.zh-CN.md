# 游玩皮肤可视化制作器

完整字段、数值范围、音频限制、Live2D 参数和 AI 设计模板见
[`SKIN-STUDIO-COMPLETE.md`](SKIN-STUDIO-COMPLETE.md)。

制作器位于 `Tools/SkinStudio/index.html`，不依赖 Unity 或服务器。Windows 可以双击
`open-studio.bat`，macOS/Linux 可以直接用浏览器打开 `index.html`。

当前同时提供 Electron 桌面封装配置。进入 `tools/SkinStudio` 后执行 `npm install`、
`npm start` 可运行窗口版，执行 `npm run dist:win` 可生成 Windows 桌面目录版，执行
`npm run dist:win:zip` 可生成可发送的 ZIP。桌面版不向皮肤页面暴露 Node API，只加载
本地制作器资源；未安装 Electron 时可继续使用浏览器版。

桌面导出通过受限的保存接口调用原生“另存为”窗口。仅信任本地主页面，只接受固定的
JSON/ZIP 导出名与限定大小的字节数据，不接受页面指定的文件路径；取消后不写磁盘。

制作器支持导入已有 ZIP 继续编辑。元素图层右侧可隐藏元素，预览区长按后可拖动布局；
重叠时当前选中的图层优先。撤回和取消撤回各保留 20 步。元素可设置标签、文字大小、
文字颜色和 PNG 覆盖，Combo、分数、判定数字可分别设置字号与颜色。Combo 与分数还可
逐个导入 `0` 到 `9` 的 PNG 数字皮肤；运行时只有在当前显示值所需数字全部存在时才切换到图片，
缺少数字会保留文字回退。

## 工作流程

已有皮肤优先点击顶部“打开皮肤文件夹”，选择解压后包含 `skin.json` 与
`ui/gameplay-ui.json` 的根目录。操作保留原名称、ID、模型路径、背景与手爪校准，完整校验
成功后才替换当前项目。关闭制作器前请导出 ZIP，下次解压后重新打开；不会自动保存大模型。

1. 在“元素图层”添加或选择元素。
2. 在右侧修改显示开关、归一化坐标、尺寸、透明度、颜色、PNG 路径和按钮标签。
3. 在预览状态中查看游玩、暂停、MISS、Combo 100、AIR、目标值归零/低于零，或填写自定义事件。
4. 选择“音符下方显示模式”。该设置会写入 `belowNoteMetric.mode`。
5. 导出 JSON，或直接导出 ZIP 皮肤包。

规则特效定位：进入“规则积木”并选中一个图片规则，勾选预览栏的“定位特效”。画布会显示
该规则，即使还没有图片也会显示占位框；长按拖动框体可改变位置，右上角手柄可调整宽高。
定位操作与普通元素一样写入撤回历史，不会改变规则触发条件。重新点击播放预览会退出定位模式。

保存安全：底部“有未保存修改”表示配置、资源或 Live2D 校准和上次成功保存不同；预览状态、
规则选择和网格开关不算修改。成功保存/导出 ZIP 后才清除提示，取消保存或校验失败会保留提示。
打开另一个 JSON、文件夹或 ZIP 前会确认放弃修改，选择继续编辑不会替换当前项目；桌面窗口关闭
也会出现同样的确认。桌面导出使用临时文件原子替换，避免导出失败损坏旧文件。

数字皮肤在“数字与文字样式”中按 Combo/分数分组设置，资源路径会写入对应的 `digits` 数组，
例如 `{ "digit": "7", "image": "ui/numbers/combo/7.png" }`。修改皮肤包后点击“保存”会
直接生成新的 ZIP；“撤回/取消撤回”记录最近 20 个编辑动作。

预览画布是 16:9 横屏比例。坐标原点在左下角，`x/y/width/height` 范围为 0 到 1。
导出的 ZIP 包含 `skin.json`、`ui/gameplay-ui.json`、`README.txt` 和制作器中选择的
PNG 文件。导出 ZIP 使用无压缩存储，便于游戏导入和排查资源。

## 支持的元素

`songInfo`、`songCover`、`scoreHud`、`comboHud`、`judgement`、`judgementImage`、
`pauseButton`、`pausePanel`、`progressBar`、`fps`、`countdown`、`touchpad`、
`airZone`、`airBoundaryBottom`、`airBoundaryTop`、`airGuide`、`trackMask`、
`touchFeedback`。

元素是已有游戏 UI 的声明式覆盖层。`pauseButton` 和 `pausePanel` 只允许修改外观、
位置、透明度和文字，皮肤不能替换暂停、返回或确认按钮的行为。隐藏判定、AIR 引导
或触控反馈只影响显示，不影响输入和成绩逻辑。

## 显示模式

- `combo`：当前 Combo 从 0 增加。
- `remaining_combo`：距离满 Combo 的剩余值。
- `score`：当前分数从 0 增加。
- `sss+`、`sss`、`ss+`、`ss`、`s+`、`s`：距离对应评级门槛的剩余分数。
- `lost_score`：只显示已经损失的分数。
- `best_score`：按当前规则显示距离最好成绩的剩余差值。

## 规则积木

属性栏的“规则积木”标签支持添加、复制、禁用和删除规则，最多 48 条。无需写代码：
选择“当”的来源与条件，再选择“然后”的图片特效或 Live2D 动作组。

- 来源：Combo、当前分数、评级、JC/J/Attack/Miss、AIR 六个传感器与移动状态、四区触控、游玩开始/结束、音符下方显示值。
- 数值条件：达到、等于、小于、小于等于。是越过阈值时触发一次，不是每帧重复触发。
- 当前显示值可以限定具体模式。例如限定 `sss+`，值小于 `0` 时触发失守滤镜；该值由游戏发布，即使 HUD 已经隐藏数字也可读取。
- 图片动作：PNG、归一化位置/尺寸、透明度、持续时间、淡入淡出、缩放、旋转。全屏滤镜用 `x=0,y=0,width=1,height=1` 的半透明 PNG，最长 30 秒。
- Live2D 动作：只允许当前已启用模型 `.model3.json` 内存在的动作组。编辑器检查组名，游戏仅加载这些规则和现有手爪/空闲设置引用的动作；忽略动作 UserData，不执行包内回调。

预设包含 Combo 100、SSS+ 目标失守、MISS、AIR 进入和左上触控。预览状态模拟单次事件与阈值变化，
静止时图片显示其配置的结束缩放/起始旋转，点击播放图标则按持续时间、淡入淡出、缩放和旋转
动态试播，结束后隐藏；停止、编辑或重开项目时取消旧动画。淡出长度限制为持续时间扣除淡入长度，
与游戏运行时一致；旋转方向按 Unity 的正 Z 方向显示。最多同时显示 24 条匹配叠加。
自定义事件支持变化前/后的数值、显示模式、评级、判定、AIR 传感器/移动状态、四区触控
及进入/离开。数值条件测试的是越过阈值的一次变化；小于 0 的规则在归零时不会触发，
须用低于零或自定义负数测试。预览测试数据不写进皮肤，也不增加撤回记录。
不在浏览器运行 Cubism 动作，也不是完整谱面播放；匹配的 Live2D 动作只报告动作组，真实播放在游戏中验证。
图片特效为临时叠加，不改变判定、成绩或账号数据。暂停时图片动画计时冻结。
只有数值上穿/下穿会触发，`active` 在触控/AIR 状态进入时触发一次，不表示持续重复。

## 场景与输入区域

“场景轨道”标签支持导入背景 PNG、轨道底图 PNG、分道线 PNG，以及背景颜色/透明度、轨道、分道线、
引导线、边缘和判定线颜色。PNG 会随 ZIP 导出；缺少引用图片时不能保存 ZIP。
游戏在真实背景和轨道渲染器中应用配置，缺图轨道回退内置贴图。未配置场景时保留原有歌曲背景。
自定义背景是替换歌曲背景，不是额外的封面层；可独立设置亮度（颜色）和透明度。

图层栏的“编辑区域”可以直接选中/添加触控板、AIR 区域、边界、引导线和轨道遮罩。
显式配置触控板/AIR 区域矩形时，游戏同时采用其识别范围；隐藏区域仅隐藏外观，不关闭采样。
全屏触控板 MOD 始终优先，皮肤不能缩小其地面区域或恢复被 MOD 关闭的 AIR。
轨道换图/换色不会移动音符投影、改变计分规则或修改谱面变速。

布局属性下的“触控板与触控爪皮肤”可以导入平板、左爪和右爪 PNG，并编辑平板的归一化位置/尺寸、
左右爪尺寸、偏移和跟手平滑参数。配置会写入 `touchOverlay`，随皮肤 ZIP 一起导出；游戏只读取这些数据，
不会从皮肤包执行代码。触控板图片和触控爪图片仍需位于 ZIP 内且路径大小写一致。

## Live2D 面板

Live2D 设置位于右侧属性栏顶部的 Live2D 标签，默认显示，包含启用开关、模型文件夹导入与选择、位置尺寸、
左右手参数和轴范围、动作组、隐藏部件、模型背景 PNG。参数名可从模型的 `.cdi3.json`
选取，动作组可从 `.model3.json` 选取；BongoCat 预设沿用游戏的屏幕左右手映射。

模型资源导入保留子目录，放入 ZIP 的 `model/` 下。导出前检查资源引用、目录穿越、
文件数、大小、PNG 尺寸、贴图总像素和缺失背景。只接纳模型数据、PNG 与许可证，
不加载 SDK 或执行代码。物理和表情文件可携带，但游戏当前不自动驱动它们。
模型文件夹先检查全部候选资源与选中模型的依赖，缺失或大小写冲突不会修改已打开项目。
Live2D 参数、背景位置、启用状态和资源导入全部纳入 20 步撤回/恢复；未绑定图片的
背景校准保留在编辑历史中，但不写入导出的空图片配置。

完整皮肤目录按原有皮肤相对路径导入，不再次添加 `model/`。导出额外校验所有 UI 图片、
实际 PNG 解码、MOC3 文件头、动作组、CDI 参数名称和大小写冲突。新项目使用独立 ID；
已有项目保留 ID，游戏内已有同 ID 时先删旧版或修改 ID，避免不同皮肤相互覆盖。

画布当前只预览模型的布局范围和背景图，不是 Cubism 实时预览；真实动作在游戏验证。
导入 JSON 会保留已有 Live2D 和其他顶层配置，避免制作器误删已有猫爪校准参数。

## 回归验证

`npm test` 验证共享路径、校准与引用规则。`tests/live2d-ui.cjs` 使用实际 BongoCat 目录，
验证完整项目导入、连续编辑、JSON 字段保留、ZIP 字节、缺图/错误参数/错误目录拦截和
桌面/手机布局。设置 `CHUNITHM_STUDIO_SKIN_ZIP` 为测试导出的 `test-output/live2d-skin.zip`，
运行 `tools/develop.ps1 -Mode Test -TestName Live2DSkinSelfTest`，Unity 会读取这份确切 ZIP，
检查原生模型透明像素、左右手、暂停、反向校准、两种分辨率的实际 UI 合成和资源释放。
测试使用临时随机 ID，不覆盖用户已安装皮肤；这不是 Android/iOS 实机测试。

`tests/rules-ui.cjs` 验证规则预设、阈值预览、启用/禁用、PNG 导入、场景资源、ZIP 重开、20 步撤回/恢复、
错误动作组拦截及桌面/手机布局。`SkinStudioRulesSelfTest` 在 Unity 验证场景解析与 PNG 缓存、路径拒绝、
禁用规则、动作事件分发以及移动后的触控板范围。改动后还需运行 `GameplaySkinCustomDisplaySelfTest` 和 `SkinSettingsSelfTest`。

`tests/studio-interactions.cjs` 验证实际 Web Animation 中间帧的透明度/缩放/角度、试播/停止/结束隐藏、
自定义数值与触控松开事件、SSS+ 低于零边界、Live2D 校准与资源撤回、坏模型/非法几何导入隔离、
实际 PNG 解码以及桌面/手机截图。共享单测同时验证淡入淡出重叠截断和非有限动画数值的安全回退。

## 安全边界

游戏和制作器只读取 JSON、PNG 和 Live2D 模型数据。皮肤包不能执行 JavaScript、DLL、Shader、Prefab
或回调；路径必须位于皮肤目录内。游戏端会限制元素数量、图片尺寸、文件扩展名、颜色、
标签长度和归一化数值。导入后若图片缺失，游戏使用内置资源或保留空白，不会从网络下载。
