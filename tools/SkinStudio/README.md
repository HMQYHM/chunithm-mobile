# Skin Studio

在 Windows、macOS 或 Linux 上可以直接双击 `index.html` 打开浏览器版，也可以运行同目录的 `open-studio.bat`。

## 桌面版

安装 Node.js 后，在本目录运行：

```text
npm install
npm start
```

生成 Windows 桌面目录版：

```text
npm run dist:win
```

输出在 `desktop-dist/win-unpacked/`，运行其中的 `CHUNITHM Mobile Skin Studio.exe`。
也可以生成可发送的 ZIP：

```text
npm run dist:win:zip
```

输出为 `desktop-dist/CHUNITHM-Mobile-Skin-Studio-win-x64.zip`。桌面壳使用 Electron 安全隔离，只加载本地制作器页面，
不开放 Node API，不允许皮肤包执行代码，也不允许页面跳转到外部网站。没有安装
Electron 依赖时，`open-studio.bat` 会自动退回浏览器版。

桌面版导出使用原生“另存为”窗口，请选择路径后保存。隔离接口只允许受信任主页面提交
`gameplay-ui.json` 和 `skin-studio-export.zip`，不接收页面指定的磁盘路径；取消保存不会写文件。

顶部“导入皮肤 ZIP”可直接打开已有皮肤继续编辑。预览元素长按约 0.26 秒后拖动位置；
重叠元素优先拖动当前图层。图层右侧圆点可单独隐藏。撤回/取消撤回各保留最近 20 次
编辑，保存会重新生成可导入的 ZIP。元素支持标签、字号、文字颜色和 PNG 覆盖；Combo、
分数、判定区域支持独立字号和颜色。Combo 和分数还可以分别导入 0-9 的 PNG 数字皮肤，
运行时缺少所需数字会回退为文字。

浏览器版和桌面版共用完全相同的皮肤格式与导出逻辑，后续 Android 版也会复用这些文件。

## Live2D 设置

编辑现有皮肤时优先使用顶部 **打开皮肤文件夹**，选择包含 `skin.json` 和
`ui/gameplay-ui.json` 的解压根目录。名称、ID、模型、背景、许可证和校准参数一起读取，
不会把已有 `model/` 再包一层。该操作替换当前编辑项目；错误目录不会清空已有项目。
只导入 JSON 时仍需补齐它引用的资源，或直接打开完整皮肤文件夹。

右侧属性栏顶部包含 **界面布局 / Live2D / 规则积木 / 场景轨道** 四个标签，默认打开 Live2D。勾选启用后，导入包含 `.model3.json` 的模型
文件夹。内部子目录会被保留，模型、MOC3、PNG、动作、参数说明和许可证一起打包。
导入时先检查缺失引用和大小写冲突，失败不会替换现有模型或资源；有缺失时也禁止导出启用 Live2D 的 ZIP。

可设置模型位置/尺寸、左右手 X/Y/按下/显示参数、四条轴范围（支持反向）、动作组、
隐藏部件，以及模型坐标中的背景 PNG。BongoCat 参数按钮只填参数映射，不自带模型。
已有 `gameplay-ui.json` 的 Live2D 校准、背景、触控和其他顶层配置不会在编辑后被丢弃。
模型启用、参数、校准、位置、背景 PNG 与模型资源导入均进入 20 步撤回记录。
还未选择图片的背景坐标也可撤回，导出时不会生成空图片配置。

当前画布显示 Live2D 布局边框和背景缩略图，**不运行 Cubism 模型或模拟猫爪动作**。
真实模型动画、裁切和触控需把导出的 ZIP 导入游戏验证。

## 使用

新增 **规则积木 / 场景轨道** 标签：规则通过“当 + 条件 + 然后”连接 Combo、分数、评级、判定、
AIR、触控与游玩事件到 PNG 动画或当前模型的 Live2D 动作组。可直接添加 Combo 100、MISS、
SSS+ 目标失守等预设，复制、禁用和删除规则。图片可淡入淡出、缩放、旋转或全屏叠加。
Live2D 原生动作仅在游戏中运行，浏览器不执行模型代码。

预览状态可选择自定义事件，填写变化前后 Combo/分数/显示值，或选择判定、评级、AIR、
触控区域与进入/离开状态。点击播放图标试播当前匹配的图片规则，支持淡入淡出、线性
缩放与旋转；停止、修改配置或切换项目会取消试播。SSS+ 失守请用“目标值低于零”，
不是“目标值归零”。自定义事件的显示模式可以独立于导出设置选取。
预览不增加撤回步骤，也不会写入皮肤；Live2D 匹配只报告动作组，不模拟原生模型。

场景支持背景/轨道/分道线 PNG 和轨道各层颜色。图层栏“编辑区域”直达触控板、AIR 等区域，
位置和尺寸同步实际识别范围；隐藏仅影响外观，全屏触控板 MOD 优先。新运行时字段需要本次
更新后的游戏，旧 APK 会忽略 `scene` 和 Live2D 规则动作。详细契约见 `docs/SKIN-STUDIO.md`。

1. 在左侧预览中选择图层，在右侧编辑显示、坐标、尺寸、颜色、图片和文字。
2. 在“音符下方显示模式”中选择 Combo、分数、评级剩余分数、已损失分数或距离最好成绩。
3. 使用“选择 PNG 图片”把图片加入当前元素。资源会放进导出 ZIP 的 `ui/studio/` 目录；Live2D 模型文件夹放入 `model/`。
4. 导出 `gameplay-ui.json` 可放入已有皮肤包的 `ui/` 目录；导出皮肤 ZIP 可直接在游戏数据管理中导入。

坐标使用 0 到 1 的游玩画布归一化坐标，原点在左下角。模型背景使用模型坐标，允许 -5 到 5 的位置和 0.01 到 10 的尺寸。制作器只生成受游戏白名单支持的元素 ID，皮肤不能执行脚本、替换按钮回调、改变判定或读取外部文件。

图片请使用 PNG。缺失图片、错误参数/动作组、损坏 PNG、错误 MOC3 文件头、超量资源和
大小写冲突会阻止 ZIP 导出。有参数说明的模型会按 `.cdi3.json` 校验映射；不提供参数说明
时仍需在游戏确认实际参数是否存在。JSON 导出只保存配置，不包含资源。

每个新项目获得独立 ID，打开现有项目保留原 ID。游戏不允许重复导入同一 ID；要保留多个
版本时先在制作器修改 ID，替换旧版时先在游戏删除旧皮肤。网页不自动持久化模型二进制；
关闭前导出 ZIP，后续解压 ZIP 后用“打开皮肤文件夹”继续编辑。
